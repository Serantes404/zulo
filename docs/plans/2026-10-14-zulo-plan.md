# Zulo: plan de implementación

> Ejecutar tarea por tarea con la skill test-driven-development. Los pasos usan checkboxes (`- [ ]`) para ir marcando el progreso.

**Objetivo:** construir una web app mobile-first en la que cada club sube la foto de su almacén, la IA genera un plano con zonas, cada zona tiene su material y los préstamos se registran con foto al coger y al devolver.

**Arquitectura:** un único proyecto Next.js (App Router) desplegado en Vercel. Supabase aporta la base de datos (Postgres con RLS), el login por magic link y el almacenamiento de fotos. La detección de zonas se hace en el servidor llamando a Ollama: en local durante el desarrollo y en Ollama Cloud en producción. La API de Ollama es la misma en los dos casos, así que solo cambian las variables de entorno.

**Tech stack:** Next.js + TypeScript, Tailwind + shadcn/ui, @supabase/ssr, zod, react-rnd, browser-image-compression, image-size, Vitest, Ollama (Qwen-VL).

**Spec:** `docs/specs/2026-10-14-zulo-design.md`

## Restricciones globales

- Toda la UI está en español y es mobile-first.
- La API key de Ollama solo se usa en el servidor. La app nunca usa la service role key de Supabase.
- Las coordenadas de las zonas están siempre en proporción `0..1` (`x, y, w, h`).
- Máximo 30 zonas por almacén. Las zonas detectadas con un área menor del 1 % se descartan.
- Paleta fija de 8 colores: `#E4572E #2E86AB #3BB273 #F2A541 #8E5DB8 #D64C8C #1B998B #6C757D`.
- Las fotos se comprimen a 1600 px de lado máximo, en JPEG con calidad 0.8. Se guardan en el bucket privado `photos`, con la ruta `{group_id}/{plans|items|loans}/{uuid}.jpg`.
- Las URLs firmadas duran 1 hora (3600 s).
- La fecha de devolución por defecto es hoy + 7 días.
- La IA tiene un timeout de 55 s, 1 reintento si responde con JSON inválido y `maxDuration = 60` en la ruta del editor.
- Códigos de error de las RPC: `NOT_AUTHENTICATED`, `FORBIDDEN`, `INVALID_INVITE`, `NOT_FOUND`, `NOT_ENOUGH_AVAILABLE`, `ALREADY_RETURNED`, `ITEM_HAS_ACTIVE_LOANS`.
- Las zonas siempre muestran su etiqueta en texto, no solo el color. Todos los inputs llevan `<label>`.

```ts
export type BoxFormat = 'relative1000' | 'pixels';
export type RawZone = { label: string; box: [number, number, number, number] };
export type Zone = { label: string; x: number; y: number; w: number; h: number };

export const MAX_ZONES = 30;
export const MIN_AREA = 0.01;

const clamp01 = (n: number) => Math.min(1, Math.max(0, n));

export function normalizeZones(
  raw: RawZone[],
  format: BoxFormat,
  img: { width: number; height: number },
): Zone[] {
  const sx = format === 'relative1000' ? 1000 : img.width;
  const sy = format === 'relative1000' ? 1000 : img.height;
  const zones: Zone[] = [];
  for (const r of raw) {
    const [a, b, c, d] = r.box;
    const x1 = clamp01(Math.min(a, c) / sx);
    const x2 = clamp01(Math.max(a, c) / sx);
    const y1 = clamp01(Math.min(b, d) / sy);
    const y2 = clamp01(Math.max(b, d) / sy);
    const w = x2 - x1;
    const h = y2 - y1;
    if (w * h < MIN_AREA) continue;
    zones.push({ label: r.label.trim(), x: x1, y: y1, w, h });
  }
  return zones.slice(0, MAX_ZONES).map((z, i) => ({ ...z, label: z.label || `Zona ${i + 1}` }));
}
```

```ts
import { z } from 'zod';
import type { RawZone } from './normalize';

const aiResponseSchema = z.object({
  zones: z.array(
    z.object({
      label: z.string().default(''),
      box: z.tuple([z.number(), z.number(), z.number(), z.number()]),
    }),
  ),
});

/** JSON schema que se pasa a Ollama en `format` para forzar la salida estructurada. */
export const aiJsonSchema = {
  type: 'object',
  properties: {
    zones: {
      type: 'array',
      items: {
        type: 'object',
        properties: {
          label: { type: 'string' },
          box: { type: 'array', items: { type: 'number' }, minItems: 4, maxItems: 4 },
        },
        required: ['label', 'box'],
      },
    },
  },
  required: ['zones'],
} as const;

export function parseAiContent(content: string): RawZone[] | null {
  let data: unknown;
  try {
    data = JSON.parse(content);
  } catch {
    return null;
  }
  const r = aiResponseSchema.safeParse(data);
  if (!r.success || r.data.zones.length === 0) return null;
  return r.data.zones;
}
```

- [ ] **Paso 5: implementar la llamada a Ollama.** `lib/ai/ollama.ts`:

```ts
import { aiJsonSchema } from './schema';

export const PROMPT = `You are looking at a photo or a hand-drawn sketch of a storage room or shelving unit.
Detect every separate compartment, shelf section or bay that could hold equipment.
For each one return a bounding box [x1, y1, x2, y2] and a short label in Spanish (max 3 words)
if a sign is readable or the contents are clearly recognisable; otherwise use an empty string.
Return only JSON like: {"zones":[{"label":"...","box":[x1,y1,x2,y2]}]}`;

export async function callVisionModel(imageBase64: string, signal?: AbortSignal): Promise<string> {
  const base = process.env.OLLAMA_BASE_URL ?? 'http://localhost:11434';
  const headers: Record<string, string> = { 'Content-Type': 'application/json' };
  if (process.env.OLLAMA_API_KEY) headers.Authorization = `Bearer ${process.env.OLLAMA_API_KEY}`;

  const res = await fetch(`${base}/api/chat`, {
    method: 'POST',
    headers,
    signal,
    body: JSON.stringify({
      model: process.env.OLLAMA_MODEL,
      stream: false,
      format: aiJsonSchema,
      options: { temperature: 0 },
      messages: [{ role: 'user', content: PROMPT, images: [imageBase64] }],
    }),
  });
  if (!res.ok) throw new Error(`OLLAMA_HTTP_${res.status}`);
  const json = (await res.json()) as { message?: { content?: string } };
  return json.message?.content ?? '';
}
```

- [ ] **Paso 6: implementar la detección.** `lib/ai/detectZones.ts`:

```ts
import { callVisionModel } from './ollama';
import { normalizeZones, type BoxFormat, type Zone } from './normalize';
import { parseAiContent } from './schema';

export const AI_TIMEOUT_MS = 55_000;

export type DetectResult =
  | { ok: true; zones: Zone[] }
  | { ok: false; reason: 'NO_ZONES' | 'TIMEOUT' | 'UNAVAILABLE' };

export async function detectZonesFromImage(
  imageBase64: string,
  img: { width: number; height: number },
  call: typeof callVisionModel = callVisionModel,
): Promise<DetectResult> {
  const format = (process.env.AI_BOX_FORMAT ?? 'pixels') as BoxFormat;
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), AI_TIMEOUT_MS);
  try {
    for (let attempt = 0; attempt < 2; attempt++) {
      const content = await call(imageBase64, controller.signal);
      const raw = parseAiContent(content);
      if (raw) {
        const zones = normalizeZones(raw, format, img);
        if (zones.length > 0) return { ok: true, zones };
      }
    }
    return { ok: false, reason: 'NO_ZONES' };
  } catch (e) {
    if (controller.signal.aborted) return { ok: false, reason: 'TIMEOUT' };
    console.error('detectZones', e);
    return { ok: false, reason: 'UNAVAILABLE' };
  } finally {
    clearTimeout(timer);
  }
}
```

```sql
select
  i.id as item_id,
  i.zone_id,
  i.quantity_total,

  (i.quantity_total - coalesce(sum(l.quantity) filter (where l.status = 'active'), 0))::int as quantity_available,

-- ========== RPC ==========
create or replace function public.create_group(p_name text) returns uuid
language plpgsql security definer set search_path = public as $$
declare g uuid;
begin
  if auth.uid() is null then raise exception 'NOT_AUTHENTICATED'; end if;
  insert into groups (name, invite_code, created_by)
    values (trim(p_name), new_invite_code(), auth.uid())
    returning id into g;
  insert into group_members (group_id, user_id, role) values (g, auth.uid(), 'admin');
  return g;
end $$;

create or replace function public.join_group(p_code text) returns uuid
language plpgsql security definer set search_path = public as $$
declare g uuid;
begin
  if auth.uid() is null then raise exception 'NOT_AUTHENTICATED'; end if;
  select id into g from groups where invite_code = p_code;
  if g is null then raise exception 'INVALID_INVITE'; end if;
  insert into group_members (group_id, user_id, role) values (g, auth.uid(), 'member')
    on conflict (group_id, user_id) do nothing;
  return g;
end $$;

create or replace function public.regenerate_invite(p_group uuid) returns text
language plpgsql security definer set search_path = public as $$
declare c text;
begin
  if not is_admin(p_group) then raise exception 'FORBIDDEN'; end if;
  update groups set invite_code = new_invite_code() where id = p_group returning invite_code into c;
  return c;
end $$;

create or replace function public.checkout_item(
  p_item uuid, p_quantity int, p_purpose text, p_due date, p_photo text
) returns uuid
language plpgsql security definer set search_path = public as $$
declare v_total int; v_out int; l uuid;
begin
  if auth.uid() is null then raise exception 'NOT_AUTHENTICATED'; end if;
  if not is_member(group_of_item(p_item)) then raise exception 'FORBIDDEN'; end if;
  select quantity_total into v_total from items where id = p_item for update;
  select coalesce(sum(quantity), 0) into v_out from loans where item_id = p_item and status = 'active';
  if p_quantity > v_total - v_out then raise exception 'NOT_ENOUGH_AVAILABLE'; end if;
  insert into loans (item_id, user_id, quantity, purpose, due_date, checkout_photo_path)
    values (p_item, auth.uid(), p_quantity, trim(p_purpose), p_due, p_photo)
    returning id into l;
  return l;
end $$;

create or replace function public.return_loan(
  p_loan uuid, p_photo text, p_condition text, p_notes text
) returns void
language plpgsql security definer set search_path = public as $$
declare v loans%rowtype;
begin
  if auth.uid() is null then raise exception 'NOT_AUTHENTICATED'; end if;
  select * into v from loans where id = p_loan for update;
  if not found then raise exception 'NOT_FOUND'; end if;
  if v.user_id <> auth.uid() and not is_admin(group_of_item(v.item_id)) then raise exception 'FORBIDDEN'; end if;
  if v.status = 'returned' then raise exception 'ALREADY_RETURNED'; end if;
  update loans set
    status = 'returned',
    return_photo_path = p_photo,
    return_condition = p_condition,
    return_notes = nullif(trim(p_notes), ''),
    returned_at = now()
  where id = p_loan;
end $$;
```

```ts
/** Evita redirecciones abiertas: solo permite rutas internas. */
export function safeNext(next: string | null | undefined): string {
  if (!next || !next.startsWith('/') || next.startsWith('//') || next.startsWith('/\\')) return '/';
  return next;
```

```ts
import { createServerClient } from '@supabase/ssr';
import { NextResponse, type NextRequest } from 'next/server';

const PUBLIC_PATHS = ['/login', '/auth'];

export async function updateSession(request: NextRequest) {
  let response = NextResponse.next({ request });
  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll: () => request.cookies.getAll(),
        setAll: (list) => {
          list.forEach(({ name, value }) => request.cookies.set(name, value));
          response = NextResponse.next({ request });
          list.forEach(({ name, value, options }) => response.cookies.set(name, value, options));
        },
      },
    },
  );

  const { data: { user } } = await supabase.auth.getUser();
  const path = request.nextUrl.pathname;
  if (!user && !PUBLIC_PATHS.some((p) => path.startsWith(p))) {
    const url = request.nextUrl.clone();
    url.pathname = '/login';
    url.search = `?next=${encodeURIComponent(path)}`;
    return NextResponse.redirect(url);
  }
  return response;
}
```

```ts
import type { SupabaseClient } from '@supabase/supabase-js';
import { createClient } from '@/lib/supabase/server';
import type { Database } from '@/lib/database.types';

export type Role = 'admin' | 'member';

export async function requireUser() {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) redirect('/login');
  return { supabase, user };
}

export async function getRole(
  supabase: SupabaseClient<Database>,
  groupId: string,
  userId: string,
): Promise<Role | null> {
  const { data } = await supabase
    .from('group_members')
    .select('role')
    .eq('group_id', groupId)
    .eq('user_id', userId)
    .maybeSingle();
  return (data?.role as Role | undefined) ?? null;
}
```

```ts
  if (code) {

      const target = onboarded ? next : `/welcome?next=${encodeURIComponent(next)}`;
```

```ts
export async function uploadPhoto(file: File, groupId: string, kind: PhotoKind): Promise<string> {
  const compressed = await imageCompression(file, {
    maxWidthOrHeight: 1600,
    initialQuality: 0.8,
    fileType: 'image/jpeg',
    useWebWorker: true,
  });
  const path = photoPath(groupId, kind);
  const { error } = await createClient()
    .storage.from('photos')
    .upload(path, compressed, { contentType: 'image/jpeg', upsert: false });
  if (error) throw error;
  return path;
}

export async function imageAspect(file: File): Promise<number> {
  const bmp = await createImageBitmap(file);
  const ratio = bmp.width / bmp.height;
```

```ts
import type { SupabaseClient } from '@supabase/supabase-js';
import type { Database } from '@/lib/database.types';

export async function signedUrls(
  supabase: SupabaseClient<Database>,
  paths: string[],
): Promise<Record<string, string>> {
  if (paths.length === 0) return {};
  const { data } = await supabase.storage.from('photos').createSignedUrls(paths, 3600);
  const out: Record<string, string> = {};
  for (const d of data ?? []) if (d.path && d.signedUrl) out[d.path] = d.signedUrl;
  return out;
}
```

```tsx
'use client';
import { useId, useState } from 'react';
import { uploadPhoto } from '@/lib/photos';
import type { PhotoKind } from '@/lib/photoPath';

type Props = {
  groupId: string;
  kind: PhotoKind;
  label: string;
  onUploaded: (path: string, file: File) => void | Promise<void>;
};

export function PhotoCapture({ groupId, kind, label, onUploaded }: Props) {
  const id = useId();
  const [preview, setPreview] = useState<string | null>(null);
  const [uploading, setUploading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function onChange(e: React.ChangeEvent<HTMLInputElement>) {
    const file = e.target.files?.[0];
    e.target.value = '';
    if (!file) return;
    setUploading(true);
    setError(null);
    let path: string;
    try {
      path = await uploadPhoto(file, groupId, kind);
    } catch {
      setError('No se ha podido subir la foto. Inténtalo de nuevo.');
      setUploading(false);
      return;
    }
    setPreview(URL.createObjectURL(file));
    setUploading(false);
    await onUploaded(path, file);
  }

  return (
    <div className="space-y-2">
      <label
        htmlFor={id}
        className="inline-flex cursor-pointer items-center rounded-md border px-4 py-2 text-sm font-medium hover:bg-muted"
      >
        {uploading ? 'Subiendo…' : label}
      </label>
      <input
        id={id}
        type="file"
        accept="image/*"
        capture={kind === 'plans' ? undefined : 'environment'}
        className="sr-only"
        onChange={onChange}
        disabled={uploading}
      />
      {kind !== 'plans' && <p className="text-xs text-muted-foreground">Haz la foto al material, no a personas.</p>}
      {preview && <img src={preview} alt="Vista previa de la foto subida" className="max-h-48 rounded-md border" />}
      {error && <p role="alert" className="text-sm text-red-700">{error}</p>}
```

```ts
import { MAX_ZONES, type Zone } from '@/lib/ai/normalize';

export const PALETTE = ['#E4572E', '#2E86AB', '#3BB273', '#F2A541', '#8E5DB8', '#D64C8C', '#1B998B', '#6C757D'] as const;
export const MIN_SIZE = 0.02;

export type EditableZone = {
  id?: string;
  key: string;
  label: string;
  color: string;
  x: number;
  y: number;
  w: number;
  h: number;
};

const uuid = () => crypto.randomUUID();

export function fromDetected(zones: Zone[], makeKey: () => string = uuid): EditableZone[] {
  return zones.map((z, i) => ({
    key: makeKey(),
    label: z.label,
    color: PALETTE[i % PALETTE.length],
    x: z.x,
    y: z.y,
    w: z.w,
    h: z.h,
  }));
}

export function newZone(index: number, makeKey: () => string = uuid): EditableZone {
  return { key: makeKey(), label: `Zona ${index + 1}`, color: PALETTE[index % PALETTE.length], x: 0.4, y: 0.4, w: 0.2, h: 0.2 };
}

export function clampZone(z: EditableZone): EditableZone {
  const w = Math.min(1, Math.max(MIN_SIZE, z.w));
  const h = Math.min(1, Math.max(MIN_SIZE, z.h));
  const x = Math.min(1 - w, Math.max(0, z.x));
  const y = Math.min(1 - h, Math.max(0, z.y));
  return { ...z, x, y, w, h };
}

export function validateZones(zones: EditableZone[]): string | null {
  if (zones.length > MAX_ZONES) return `Máximo ${MAX_ZONES} zonas por almacén.`;
  for (const z of zones) {
    if (!z.label.trim()) return 'Todas las zonas necesitan un nombre.';
    if (z.label.trim().length > 60) return 'Los nombres de zona tienen un máximo de 60 caracteres.';
    if (!(PALETTE as readonly string[]).includes(z.color)) return 'Color no válido.';
    if (![z.x, z.y, z.w, z.h].every(Number.isFinite)) return 'Hay una zona con una posición no válida.';
  }
  return null;
}
```

```ts
'use server';
import { revalidatePath } from 'next/cache';
import { imageSize } from 'image-size';
import { requireUser, getRole } from '@/lib/auth';
import { signedUrls } from '@/lib/signed';
import { detectZonesFromImage, type DetectResult } from '@/lib/ai/detectZones';
import { clampZone, validateZones, type EditableZone } from '@/lib/zones';

async function requireAdmin(groupId: string) {
  const ctx = await requireUser();
  if ((await getRole(ctx.supabase, groupId, ctx.user.id)) !== 'admin') throw new Error('FORBIDDEN');
  return ctx;
}

export async function setPlanImage(
  groupId: string,
  warehouseId: string,
  path: string,
  aspectRatio: number,
): Promise<{ url: string } | { error: string }> {
  const { supabase } = await requireAdmin(groupId);
  if (!path.startsWith(`${groupId}/plans/`) || !Number.isFinite(aspectRatio) || aspectRatio <= 0) {
    return { error: 'Foto no válida.' };
  }
  const { error } = await supabase
    .from('warehouses')
    .update({ plan_image_path: path, aspect_ratio: aspectRatio })
    .eq('id', warehouseId)
    .eq('group_id', groupId);
  if (error) return { error: 'No se ha podido guardar la foto del plano.' };
  const urls = await signedUrls(supabase, [path]);
  return urls[path] ? { url: urls[path] } : { error: 'No se ha podido cargar la foto.' };
}

export async function detectZonesAction(groupId: string, warehouseId: string): Promise<DetectResult> {
  const { supabase } = await requireAdmin(groupId);
  const { data: wh } = await supabase
    .from('warehouses')
    .select('plan_image_path')
    .eq('id', warehouseId)
    .eq('group_id', groupId)
    .single();
  if (!wh?.plan_image_path) return { ok: false, reason: 'NO_ZONES' };
  const { data: blob, error } = await supabase.storage.from('photos').download(wh.plan_image_path);
  if (error || !blob) return { ok: false, reason: 'UNAVAILABLE' };
  const buf = Buffer.from(await blob.arrayBuffer());
  const { width, height } = imageSize(buf);
  if (!width || !height) return { ok: false, reason: 'UNAVAILABLE' };
  return detectZonesFromImage(buf.toString('base64'), { width, height });
}

export async function saveZones(
  groupId: string,
  warehouseId: string,
  zones: EditableZone[],
): Promise<{ ok: true } | { error: string }> {
  const invalid = validateZones(zones);
  if (invalid) return { error: invalid };
  const { supabase } = await requireAdmin(groupId);

  const { data: existing } = await supabase.from('zones').select('id, label').eq('warehouse_id', warehouseId);
  const keep = new Set(zones.filter((z) => z.id).map((z) => z.id));
  const toDelete = (existing ?? []).filter((z) => !keep.has(z.id));

  if (toDelete.length > 0) {
    const ids = toDelete.map((z) => z.id);
    const { data: withItems } = await supabase.from('items').select('zone_id').in('zone_id', ids);
    const blocked = toDelete.filter((z) => withItems?.some((i) => i.zone_id === z.id));
    if (blocked.length > 0) {
      return {
        error: `Mueve o borra el material de ${blocked.map((z) => `«${z.label}»`).join(', ')} antes de eliminar esas zonas.`,
      };
    }
    const { error } = await supabase.from('zones').delete().in('id', ids);
    if (error) return { error: 'No se han podido borrar las zonas.' };
  }

  const rows = zones.map(clampZone).map((z) => ({
    id: z.id,
    warehouse_id: warehouseId,
    label: z.label.trim(),
    color: z.color,
    x: z.x,
    y: z.y,
    w: z.w,
    h: z.h,
  }));
  const updates = rows.filter((r) => r.id).map((r) => ({ ...r, id: r.id as string }));
  const inserts = rows.filter((r) => !r.id).map(({ id: _id, ...r }) => r);

  if (updates.length > 0) {
    const { error } = await supabase.from('zones').upsert(updates);
    if (error) return { error: 'No se han podido guardar los cambios.' };
  }
  if (inserts.length > 0) {
    const { error } = await supabase.from('zones').insert(inserts);
    if (error) return { error: 'No se han podido crear las zonas nuevas.' };
  }

  revalidatePath(`/g/${groupId}/w/${warehouseId}`);
  return { ok: true };
}
```
Nota: guardar no es atómico (borrar, actualizar e insertar son tres llamadas). Para el MVP es aceptable, porque solo los admins editan y la operación es rara.

```tsx
import { Rnd } from 'react-rnd';
import { PALETTE, clampZone, newZone, type EditableZone } from '@/lib/zones';

import { Input } from '@/components/ui/input';

  imageUrl: string | null;
  aspectRatio: number;
  zones: EditableZone[];
  onChange: (zones: EditableZone[]) => void;
};

const GRID =
  'linear-gradient(to right, #e5e7eb 1px, transparent 1px), linear-gradient(to bottom, #e5e7eb 1px, transparent 1px)';

export function ZoneEditor({ imageUrl, aspectRatio, zones, onChange }: Props) {
  const ref = useRef<HTMLDivElement>(null);
  const [width, setWidth] = useState(0);
  const [selected, setSelected] = useState<string | null>(null);

  useEffect(() => {
    const el = ref.current;
    if (!el) return;
    const ro = new ResizeObserver(([entry]) => setWidth(entry.contentRect.width));
    ro.observe(el);
    return () => ro.disconnect();

  const update = (key: string, patch: Partial<EditableZone>) =>
    onChange(zones.map((z) => (z.key === key ? clampZone({ ...z, ...patch }) : z)));

    onChange(zones.filter((z) => z.key !== key));
    setSelected(null);
  };
  const add = () => {
    const z = newZone(zones.length);
    onChange([...zones, z]);
    setSelected(z.key);
  };
  const sel = zones.find((z) => z.key === selected);

  return (
    <div className="space-y-3">
      <div
        ref={ref}
        className="relative w-full touch-none overflow-hidden rounded-lg border"

          backgroundImage: imageUrl ? `url("${imageUrl}")` : GRID,
          backgroundSize: imageUrl ? '100% 100%' : '24px 24px',

          zones.map((z) => (

              bounds="parent"

              position={{ x: z.x * width, y: z.y * height }}
              onDragStart={() => setSelected(z.key)}

                update(z.key, { w: el.offsetWidth / width, h: el.offsetHeight / height, x: pos.x / width, y: pos.y / height })

                border: `2px solid ${z.color}`,
                background: `${z.color}33`,
                outline: selected === z.key ? '2px dashed #111' : undefined,
              }}
            >
              <span className="absolute left-1 top-1 rounded bg-white/90 px-1.5 text-xs font-medium text-gray-900">
                {z.label}
              </span>
            </Rnd>
          ))}
      </div>

      <Button type="button" variant="outline" onClick={add}>Añadir zona</Button>

      {sel ? (
        <div className="space-y-3 rounded-lg border p-3">
          <div className="space-y-1">

  );
```

```tsx
'use client';
import { useRef, useState } from 'react';
import { useRouter } from 'next/navigation';
import { ZoneEditor } from '@/components/ZoneEditor';
import { PhotoCapture } from '@/components/PhotoCapture';
import { Button } from '@/components/ui/button';
import { imageAspect } from '@/lib/photos';
import { fromDetected, type EditableZone } from '@/lib/zones';
import type { DetectResult } from '@/lib/ai/detectZones';
import { detectZonesAction, saveZones, setPlanImage } from './actions';

const AI_MESSAGES = {
  NO_ZONES: 'No he podido detectar zonas, dibújalas tú.',
  TIMEOUT: 'La IA ha tardado demasiado. Dibuja las zonas a mano o inténtalo de nuevo.',
  UNAVAILABLE: 'La IA no está disponible ahora. Puedes dibujar las zonas a mano.',
} as const;

type Props = {
  groupId: string;
  warehouseId: string;
  name: string;
  imageUrl: string | null;
  aspectRatio: number;
  initialZones: EditableZone[];
};

export function PlanEditorClient({ groupId, warehouseId, name, imageUrl: initialUrl, aspectRatio, initialZones }: Props) {
  const router = useRouter();
  const [imageUrl, setImageUrl] = useState(initialUrl);
  const [aspect, setAspect] = useState(aspectRatio);
  const [zones, setZones] = useState(initialZones);
  const [manual, setManual] = useState(initialZones.length > 0);
  const [detecting, setDetecting] = useState(false);
  const [saving, setSaving] = useState(false);
  const [message, setMessage] = useState<string | null>(null);
  const runId = useRef(0);

  async function runDetection() {
    const id = ++runId.current;
    setDetecting(true);
    setMessage(null);
    let r: DetectResult;
    try {
      r = await detectZonesAction(groupId, warehouseId);
    } catch {
      r = { ok: false as const, reason: 'UNAVAILABLE' as const };
    }
    if (id !== runId.current) return; // se canceló mientras esperaba
    setDetecting(false);
    if (r.ok) setZones(fromDetected(r.zones));
    else setMessage(AI_MESSAGES[r.reason]);
  }

  function cancelDetection() {
    runId.current++;
    setDetecting(false);
    setMessage('Detección cancelada. Puedes dibujar las zonas a mano.');
  }

  async function onPlanUploaded(path: string, file: File) {
    const ratio = await imageAspect(file);
    const r = await setPlanImage(groupId, warehouseId, path, ratio);
    if ('error' in r) {
      setMessage(r.error);
      return;
    }
    setImageUrl(r.url);
    setAspect(ratio);
    setManual(true);
    if (zones.length === 0) await runDetection();
  }

  async function redetect() {
    if (zones.length > 0 && !confirm('Esto reemplaza las zonas actuales por las que detecte la IA. ¿Seguir?')) return;
    await runDetection();
  }

  async function save() {
    setSaving(true);
    setMessage(null);
    const r = await saveZones(groupId, warehouseId, zones);
    setSaving(false);
    if ('error' in r) setMessage(r.error);
    else router.push(`/g/${groupId}/w/${warehouseId}`);
  }

  const showEditor = imageUrl !== null || manual;

  return (
    <main className="mx-auto max-w-3xl space-y-4 p-4">
      <h1 className="text-2xl font-semibold">Plano de {name}</h1>

      {!showEditor && (
        <div className="space-y-3">
          <p>Sube una foto o un boceto del almacén y la IA propondrá las zonas.</p>
          <PhotoCapture groupId={groupId} kind="plans" label="Subir foto o boceto" onUploaded={onPlanUploaded} />
          <Button variant="outline" onClick={() => setManual(true)}>Dibujar a mano sobre cuadrícula</Button>
        </div>
      )}

      {detecting && (
        <div role="status" className="flex items-center gap-3 rounded-lg border p-3">
          <span>Detectando zonas… puede tardar hasta un minuto.</span>
          <Button variant="outline" size="sm" onClick={cancelDetection}>Cancelar</Button>
        </div>
      )}

      {message && <p role="alert" className="text-sm text-red-700">{message}</p>}

      {showEditor && !detecting && (
        <>
          <ZoneEditor imageUrl={imageUrl} aspectRatio={aspect} zones={zones} onChange={setZones} />
          <div className="flex flex-wrap items-start gap-2">
            {imageUrl ? (
              <Button variant="outline" onClick={redetect}>Volver a detectar con IA</Button>
            ) : (
              <PhotoCapture groupId={groupId} kind="plans" label="Añadir foto de fondo" onUploaded={onPlanUploaded} />
            )}
            <Button onClick={save} disabled={saving}>{saving ? 'Guardando…' : 'Guardar plano'}</Button>
          </div>
        </>
      )}
    </main>
  );
}
```

```ts
export type ItemRow = {
  id: string;
  name: string;
  zone_id: string;
  quantity_total: number;
  notes: string | null;
  photo_path: string | null;
};
export type AvailRow = {
  item_id: string | null;
  quantity_out: number | null;
  quantity_available: number | null;
  has_overdue: boolean | null;
};
export type ItemWithAvail = ItemRow & { out: number; available: number; overdue: boolean };
export type ZoneStatus = 'overdue' | 'out' | 'ok';

export function mergeAvailability(items: ItemRow[], avail: AvailRow[]): ItemWithAvail[] {
  const byId = new Map(avail.filter((a) => a.item_id).map((a) => [a.item_id as string, a]));
  return items.map((i) => {
    const a = byId.get(i.id);
    return {
      ...i,
      out: a?.quantity_out ?? 0,
      available: a?.quantity_available ?? i.quantity_total,
      overdue: a?.has_overdue ?? false,
    };
  });
}

export function zoneStatus(items: ItemWithAvail[]): ZoneStatus {
  if (items.some((i) => i.overdue)) return 'overdue';
  if (items.some((i) => i.out > 0)) return 'out';
  return 'ok';
}

export function availabilityLabel(i: { available: number; quantity_total: number }): string {
  if (i.available === i.quantity_total) return `${i.available} disponible${i.available === 1 ? '' : 's'}`;
  return `${i.available} de ${i.quantity_total} disponibles`;
}

const fold = (s: string) => s.normalize('NFD').replace(/\p{Diacritic}/gu, '').toLowerCase().trim();

export function searchItems<T extends { name: string }>(items: T[], query: string): T[] {
  const q = fold(query);
  if (!q) return [];
  return items.filter((i) => fold(i.name).includes(q));
}
```

```ts
export function toISODate(d: Date): string {
  const m = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${d.getFullYear()}-${m}-${day}`;
}

export function defaultDueDate(today: Date = new Date(), days = 7): string {
  const d = new Date(today);
  d.setDate(d.getDate() + days);
  return toISODate(d);
}

export function isOverdue(dueDate: string, today: Date = new Date()): boolean {
  return dueDate < toISODate(today);
}
```

```ts
import { requireUser } from '@/lib/auth';
import { checkoutSchema, itemSchema } from '@/lib/schemas';
import { rpcErrorMessage } from '@/lib/errors';
import { toISODate } from '@/lib/dates';
import { safeNext } from '@/lib/safeNext';

export type ActionResult = { ok: true } | { error: string };

export async function checkoutAction(input: unknown): Promise<ActionResult> {
  const p = checkoutSchema.safeParse(input);
  if (!p.success) return { error: 'Revisa los datos del formulario.' };
  const { itemId, quantity, purpose, dueDate, photoPath } = p.data;
  // margen de 1 día porque el servidor usa UTC
  if (dueDate < toISODate(new Date(Date.now() - 86_400_000))) {
    return { error: 'La fecha de devolución no puede ser anterior a hoy.' };
  }
  const { supabase } = await requireUser();
  const { error } = await supabase.rpc('checkout_item', {
    p_item: itemId,
    p_quantity: quantity,
    p_purpose: purpose,
    p_due: dueDate,
    p_photo: photoPath,
  });
  if (error) {
    revalidatePath(`/item/${itemId}`);
    if (error.message.includes('NOT_ENOUGH_AVAILABLE')) {
      const { data } = await supabase.from('item_availability').select('quantity_available').eq('item_id', itemId).maybeSingle();
      return { error: `Solo quedan ${data?.quantity_available ?? 0} disponibles.` };
    }
    return { error: rpcErrorMessage(error.message) };
  }
  revalidatePath(`/item/${itemId}`);
  return { ok: true };
}

export async function updateItem(itemId: string, _prev: ActionResult | null, formData: FormData): Promise<ActionResult> {
  const p = itemSchema.safeParse({
    name: formData.get('name'),
    quantity: formData.get('quantity'),
    notes: formData.get('notes') || undefined,
  });
  if (!p.success) return { error: 'Revisa el nombre y la cantidad.' };
  const { supabase } = await requireUser();
  const { data: a } = await supabase.from('item_availability').select('quantity_out').eq('item_id', itemId).maybeSingle();
  const out = a?.quantity_out ?? 0;
  if (p.data.quantity < out) return { error: `Hay ${out} unidades prestadas: la cantidad total no puede ser menor.` };
  const { error } = await supabase
    .from('items')
    .update({ name: p.data.name, quantity_total: p.data.quantity, notes: p.data.notes ?? null })
    .eq('id', itemId);
  if (error) return { error: 'No se han podido guardar los cambios.' };
  revalidatePath(`/item/${itemId}`);
  return { ok: true };
}

export async function deleteItem(itemId: string, backTo: string): Promise<ActionResult> {
  const { supabase } = await requireUser();
  const { error } = await supabase.from('items').delete().eq('id', itemId);
  if (error) return { error: rpcErrorMessage(error.message) };
  redirect(safeNext(backTo));
}

export async function setItemPhoto(itemId: string, path: string): Promise<ActionResult> {
  const { supabase } = await requireUser();
  const { error } = await supabase.from('items').update({ photo_path: path }).eq('id', itemId);
  if (error) return { error: 'No se ha podido guardar la foto.' };
  revalidatePath(`/item/${itemId}`);
  return { ok: true };
}
```
